Правило розподілу витрат

Довідник призначений для реєстрації і настройки правил розподілу матеріалів і робіт, а також статей витрат за підрозділами , виробничим етапам та документами випуску.

Залежно від обраного призначення правила доступні різні варіанти бази розподілу:

  • Розподіл статей витрат за етапах виробництва і документами випуску - для даного призначення доступні бази розподілу, що автоматично розраховуються:
    Кількість (об'єм, вага) зазначених матеріалів
    Кількість (об'єм, вага) продукції
    Планова вартість продукції
    Кількість робіт зазначених видів
    Сума матеріальних витрат
    Сума витрат на оплату праці
    Нормативна сума витрат на оплату праці.
  • Розподіл статей витрат по підрозділах - доступні бази розподілу Сума матеріальних витрат, Сума витрат на оплату праці, а також можливе зазначення, що значення бази розподілу Вводиться вручну щомісяця або Вводиться вручну при зміні. При виборі останніх двох варіантів список значень, що визначає базу розподілу, вводиться в окремій формі при натисканні на гіперпосилання Значення. При виборі варіанту Вводиться вручну при зміні значення вводяться тільки у разі їх зміни, а при виборі Вводиться вручну щомісяця значення необхідно вводити щомісячно.

Приклад. Розподіл витрат по підрозділах пропорційний обсягу спожитої електроенергії підрозділами підприємства. Інформація про обсяг спожитої електроенергії вводиться щомісяця. Для цього необхідно створити показник для розподілу витрат по підрозділах Об’єм спожитої електроенергії, для якого встановити, що він Вводиться вручну щомісяця. Таким чином, з'являється можливість щомісяця розподіляти витрати відповідно до введеного поточного значення показника.
  • Розподіл матеріалів і робіт- доступний наступний ряд баз розподілу:
    Кількість (об’єм, вага) зазначених матеріалів
    Кількість (об’єм, вага) продукції
    Планова вартість продукції
    Кількість робіт зазначених видів
    Норматив витрати даного матеріалу

Кількість робіт зазначених видів

Планова вартість продукції

Норматив витрати даного матеріалу

Сума матеріальних витрат

Сума витрат на оплату праці

Нормативна сума витрат на оплату праці

Кількість (б’єм, вага) зазначених матеріалів

Для цієї бази розподілу існує можливість вказати матеріали або групи матеріалів, по яких буде будуватися дана база. Для побудови бази програма вибирає дані про використання зазначених матеріалів у виробництві протягом місяця. Для бази За об’ємом, вагою кількість матеріалу множиться на коефіцієнт об’єму(ваги) з картки номенклатури.

Кількість (об’єм, вага) продукції

База розподілу збирається з інформації випусків без розпоряджень та інформації про вироблену продукцію за замовленнями. При цьому, враховуючи, що виробничий цикл за замовленням може бути тривалим (кілька місяців), то коректним з економічної точки зору є використання інформації про виконані етапи виробництва і планову кількість випуску за формулою:
Розрахункова кількість випуску за замовленням = Планова кількість випуску(береться із замовлення) *Кількість виконаних етапів в поточному місяці / Загальна кількість запланованих етапів за замовленням.

Кількість робіт зазначених видів

База будується на підставі даних про віднесення трудовитрат із зазначеними видами робіт на продукцію, що випускається протягом місяця

Планова вартість продукції

Дана база розподілу будується аналогічно базі Кількість продукції, потім кількість продукції множиться на планову ціну. Вид планової ціни встановлюється в НДІ та адміністрування/Виробництво/Планові ціни матеріалів, робіт і відходів

Норматив витрати даного матеріалу

Дані для бази вибираються аналогічно як для бази Кількість продукції, потім для випусків без розпорядженнянорматив витрат матеріалу, що розподіляється, береться зі специфікації, зазначеної в рядках документа випуску, а для випусків за замовленнями норматив береться зі специфікації, зазначеної у відповідному рядку табличної частини Продукція Замовлення на виробництво (або Замовлення переробнику)

Сума матеріальних витрат

Дані для бази вибираються з регістру накопичення Партії незавершеного виробництва, враховується сумова оцінка матеріальних витрат, що надійшли протягом місяця.

Сума витрат на оплату праці

База формується за даними регістрів Трудовитрати незавершеного виробництва і Трудовитрати на випуск без розпоряджень, при цьому береться фактична сума трудовитрат.

Нормативна сума витрат на оплату праці

База будується аналогічно базі Сума витрат на оплату праці, але при цьому для розрахунку береться нормативна вартість, а не фактична.

Для правил розподілу статей витрат по підрозділах доступна вказівки напряму розподілу витрат. Вибір одного з варіантів визначає те, як витрата буде розподілятися по підрозділам.

Якщо в настройках Підрозділу відключено використання документа Списання витрат на випуск, то застосовуються такі бази розподілу: Кількість продукції, Об’єм продукції, Вага продукції, Планова вартість продукції.

Також в елементі довідника можна встановити відбір за групами (видами) продукції, який буде враховуватися при побудові бази розподілу, і встановити статтю калькуляції, яка буде автоматично підставлятися в документ розподілу при виборі даного правила розподілу
