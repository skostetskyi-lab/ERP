Переоцінка ОЗ

Документ призначений для відображення в системі фактів переоцінки основних засобів.

При введенні документа уточнюються реквізити:

  • Організація-організація, в якій прийняті до обліку основні засоби.
  • Місцезнаходження ОЗ- підрозділ організації, в якому прийняті до обліку основні засоби
  • Подія ОЗ-найменування події переоцінки основного засобу, що відображається документом.
  • Стаття витрат, Аналітика витрат-напрямок нарахування витрат у разі уцінки
  • Стаття доходів, Аналітика доходів-напрямок нарахування доходів у разі дооцінки після уцінки


У табличній частині уточнюється список основних засобів, призначених для переоцінки. Для кожного ОЗ вручну вказується Справедлива вартість.

Для швидкого заповнення документа групою однотипних основних засобів потрібно ввести в табличне полі хоча б один такий об'єкт і автоматично заповнити табличне поле по кнопці Заповнити- По найменуванню.
