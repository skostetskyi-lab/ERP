Виробіток співробітників

Документ призначений для реєстрації факту виконання робіт співробітниками і передачі інформації для нарахування заробітної плати (якщо включений розрахунок зарплати).

Для можливості розрахунку зарплати потрібно включення функціональної опції Використовувати програму для кадрового обліку і розрахунку заробітної плати в розділі НДІ і адміністрування - Кадри.

Документ реєструє в підсистемі з розрахунку заробітної плати дані за показником Відрядний заробіток.

Характер робіт, що формлюються, залежить від значення поля Операція:

  • Виробництво - для робіт з виробництва продукції. При включеному прапорі За замовленням відображає роботи співробітників за Маршрутними листами виробництва. У табличній частині Види робіт вказуються маршрутні листи і статті калькуляції. Витрати, пов'язані з виконанням таких робіт, будуть віднесені на етапи виробництва, закріплені за маршрутними листами. При вимкненому прапорі відображає роботи з виробництва продукції без замовлень на виробництво. У документі вказується підрозділ, за яким закріплюються виконані роботи, і перелік видів робіт. Розподіл трудовитрат на випуски продукції без замовлень виконується документом Списання витрат на випуск. Якщо у виробничому підрозділі документ Списання витрат на випуск не використовується, то реєстрація трудовитрат недоступна.
  • Ремонт-для робіт по виконанню Замовлень на ремонт. У табличній частині Види робіт вказуються замовлення на ремонт, Спосіб відображення зарплати. Витрати, пов'язані з оплатою виконаних робіт, будуть віднесені на статті витрат, зазначені у способі відображення.
  • Інші роботи - для інших робіт. У табличній частині Види робіт вказуються замовлення на ремонт, Спосіб відображення зарплати. Витрати, пов'язані з оплатою виконаних робіт, будуть віднесені на статті витрат, зазначені у способі відображення.

Для операції Виробництво

у табличній частині Види робіт вказується Група (вид) продукції, для виробництва якої виконувалися роботи. При заповненні документа за розпорядженнями Група (вид) продукції заповнюється автоматично і не доступна для зміни.

Таблична частина Співробітники містить співробітників організації і може бути заповнена автоматично (кнопка Заповнити) за поточним складом бригади.

Якщо перемикач Застосовувати розподіл по КТУ встановлений, то розподіл між співробітниками виконується пропорційно коефіцієнтів трудової участі для документа в цілому, в іншому випадку для кожного рядка табличної частини Види робіт зазначаються виконавці та обсяг виконаних робіт.
