Виробіток НМА

Документ Виробіток НМА призначений для реєстрації обсягу виробленої продукції (виконаних робіт) для нарахування амортизації нематеріальних активів.

У документі уточнюється обсяг виробленої продукції (виконаних робіт) по кожному нематеріальному активу.

  • Нематеріальний актив - нематеріальний актив.
  • Обсяг робіт - обсяг виробленої продукції (виконаних робіт).
