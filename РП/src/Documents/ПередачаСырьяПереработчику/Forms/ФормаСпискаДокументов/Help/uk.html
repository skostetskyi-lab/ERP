Друк

Створення нової передачі сировини переробнику
  • Перейти на закладку До оформлення.
  • У списку розпоряджень вибрати рядок з необхідним Замовленням переробнику.
  • Натиснути Оформити по замовленню або Оформити по ордерах.
  • Буде створено новий документ Передача сировини переробнику.


Новий документ буде автоматично заповнений даними із замовлення або оформлених ордерів по замовленню. Менеджеру залишається тільки скорегувати склад номенклатурних позицій, їх кількість і, в разі потреби, вказати заставну вартість.
