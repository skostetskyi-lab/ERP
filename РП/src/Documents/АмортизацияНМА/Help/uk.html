Амортизація НМА

Документ призначений для відображення в системі операцій з розрахунку амортизації НМА. Для уникнення повторного нарахування зі складу активів виключаються об'єкти, по яких амортизація вже була нарахована протягом звітного періоду, наступними документами:

  • Підготовка до передачі;
  • Переоцінка НМА;
  • Списання.

Гіперпосилання форми документа Настройки відображення витрат для швидкого переходу до параметрів відображення в регламентованому обліку буде пофарбоване в червоний колір у разі відсутності рахунків відображення витрат за об'єктами, що підлягають амортизації та погашення вартості. Також, наявність помилки блокує проведення документа, потрібно заповнити рахунки відображення витрат перед виконанням розрахунку.
